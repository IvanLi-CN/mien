# 已知限制

本文是 `docs/TEST-PLAN.md:295`（PKG-008）要求的已知限制清单的唯一事实源：发布说明必须逐类列出这些限制，`scripts/release/release-notes.mjs check` 会强制六类齐全。

每条限制都写明"现象"与"用户会看到什么"，因为 PKG-008 要求发布说明对外可读，不只是内部备忘。禁止在这一步引入"不可检测"之类的卖点式表达（`docs/PRD.md:51`）。

## 1. 内核缺陷

fingerprint-chromium 是基于 Chromium 的定制内核，不是上游 Chrome。以下差异会让检测方与真实 Chrome 区分开：

- 版本号停留在清单锁定的构建，不随 Chrome 同步更新。清单 `version` 与上游 Chrome 的差距本身就是信号。
- 部分 Chromium 上游缺陷在此构建中存在，且不会通过升级 Chrome 修复。逐条缺陷编号记录在 `docs/spikes/kernel/` 的能力清单里。
- 不提供 Chrome 官方渠道的安全更新；本项目必须自行升级内核并重新取证。

用户可见影响：依赖精确 Chrome 版本或上游补丁状态做比对的站点，可能把该环境判为非 Chrome。

## 2. 伪有头

伪有头（pseudo-headful）指浏览器进程以无头模式运行，但对页面暴露"有窗口"的信号。它是显式降级选项，不是默认路径（`docs/ARCHITECTURE.md:13`）。

- 不存在真实窗口，`window.open` 的行为、窗口尺寸约束与真实有头不一致。
- 依赖真实合成器或 GPU 输出的信号（例如某些 WebGL 上下文细节、`requestAnimationFrame` 节奏）与有头环境有差异。
- 显示相关的指纹（`screen`、窗口内外尺寸、设备像素比）只能声明，不能由真实窗口兑现。

用户可见影响：依赖真实渲染或窗口生命周期的页面可能失败；指纹一致性弱于真实有头。

## 3. TUIC

TUIC 不进入 v1（`docs/ARCHITECTURE.md:550`）。能力清单不会把 TUIC 列为可用协议，也不得在 UI 或文档中作为 v1 能力宣传（`docs/PRD.md:326`）。

- 导入 TUIC 分享链接必须被明确拒绝，不能静默降级到其他协议或直连。
- 已有配置引用 TUIC 时，启动必须失败并给出稳定错误码，而不是回退。

用户可见影响：需要 TUIC 的节点无法在本版本使用；这是产品边界，不是缺陷。

## 4. 节点 bootstrap 泄漏

只有代理节点主机名允许本地 bootstrap 解析；目标域名的 DNS 查询必须由节点远程解析（`docs/PRD.md:166`）。

- 节点主机名在本地解析时，本机 DNS 查询会暴露该主机名，以及"有人正在连接它"这一事实。
- 若节点主机名本身是敏感信息，本机网络与上游 DNS 解析器能看到它。
- 目标域名的解析在使用标准代理连接路径时不走本地，但代理协议自身的实现差异由能力清单标注。

用户可见影响：连接的**节点**主机名可能被本地网络观察到；被访问的**目标**域名不因此泄漏。

## 5. 跨系统限制

宿主操作系统的差异不会被抹平，指纹规格只能声明自己覆盖到什么程度：

- 宿主绑定的显示属性（分辨率、缩放、色深）来自宿主，不能虚构为另一种系统。
- 字体枚举结果来自宿主字体集合。容器镜像内安装的字体集固定，宿主则随系统变化。
- 跨系统画像（例如在 macOS 宿主上声明 Windows）不是 v1 能力：`platform` 类指纹与宿主不一致时必须显式标注为不支持，而不是静默改成宿主值。
- 时区与语言来自宿主，声明的值必须与宿主一致，否则产生互相矛盾的信号。

用户可见影响：在同一台机器上，不同宿主之间的一致性有上限；声明跨系统时会被判为不一致。

## 6. 共享引擎故障域

代理引擎（Xray-core）以共享出站方式运行，多档案复用同一引擎进程与出站池。

- 引擎进程崩溃会影响所有正在使用它的档案，而不是单个档案。
- 引擎重启会让所有相关档案的连接瞬断，需要重新建立。
- 引擎与档案的引用计数归零时才回收；存在档案引用时，引擎不会因单个档案停止而退出。

用户可见影响：一个档案的异常使用可能影响同一引擎上的其他档案；这是共享设计换取资源效率的代价。

- 新增限制类别时，先改本文，再改 `scripts/release/release-notes.mjs` 的类别表；两处不一致会让门禁失败。
- 每条限制必须能指向事实来源（文档行号或证据文件）。无法指向来源的条目不得进入本文。
- 限制被修复后必须从本文删除，并在发布说明中写明修复版本；不允许保留"历史限制"章节。
